# Security

Please don't report a security problem in a public issue. Use [Report a vulnerability](https://github.com/speys-app/speys-local/security/advisories/new) on GitHub, which reaches the maintainers privately.

Say what an attacker could do and how to reproduce it. Fixes go to the `main` branch; there are no separately supported versions.

Speys Local runs on `127.0.0.1` with your permissions. Applets have no sandbox, so a backend can do anything you can. An applet you installed or wrote doing that is expected; a website, or a Store applet that wasn't reviewed for it, doing that is a report worth sending.
